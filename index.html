ABOUT THIS JOURNAL

One game. Clear evidence.

This is the 2003 Game Boy Advance title, not Final Fantasy Tactics or Tactics A2. The guide describes game content; the numbers here describe this project's selected recovery inventories.

Reference: FFSKY FFTA guide by Random and contributors. Guide text and tables are not reproduced. Title artwork © Square, from the guide's official-wallpaper collection, used to identify the game; not covered by this project's metadata license. This is an unofficial fan research project.

Daily updates publish new verified data snapshots. A redeployment alone does not advance the snapshot date. No private repository connection, game payloads, implementation details or conversations are distributed.
