Counting rules & data

The rewrite percentage is original ASM bytes covered by byte-identical C divided by all known original ASM bytes. Generated C size is a separate measure. Matched ASM totals combine the verified ROM snapshot and registered local exact results, deduplicated by original ranges. Bytes include literals and alignment. Local matching is separate from independent acceptance and integration.

Rates include the full elapsed time. Frozen tasks are not automatically accepted. Unassigned rows retain provisional classification. Missing ledger receipts can undercount output; game-wide completion is unknown.
