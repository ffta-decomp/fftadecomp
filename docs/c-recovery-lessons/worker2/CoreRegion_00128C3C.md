# Seven-arm unit reduction: signed local and packed byte storage

`CoreRegion_00128C3C` reduces one selected unit value using a descriptor-selected divisor. Six arms divide full-width unit properties; the seventh uses signed division of ten. Quotients wrap to a signed 16-bit local before zero and upper-limit checks. The first two arms also clamp the corresponding current value to its reduced maximum. The return is the reduction low byte.

The original byte-two selector is extracted by LDRB followed by LSL29/LSR29. A raw mask introduced an extra register; an unpacked logical bitfield incorrectly emitted a word load. The physical packed three-byte descriptor, with an explicit size assertion, restored the byte access. Do not transfer unpacked bitfields to a bounded byte layout.

An unsigned 16-bit amount with casts had correct bounded arithmetic intentions but the compiler tested zero before sign-extension and repeated the extension in every upper-limit branch. A signed 16-bit local reproduced the observed shared signed value, register allocation and seven-arm joins. This removed eight generated bytes and matched all514 original bytes, including478 instruction bytes and36 literal/table bytes. The seven switch words are28 bytes within that36-byte literal total. Two compiler section-alignment bytes are outside the original span and trimmed separately.

Three source causes and one physical-layout repair took four compiles. The final fixed-O2 result is a whole-original local exact gate, not integration or a new natural-domain gameplay test. Preserve ordinary RAM field accesses after helpers, the unit-pointer snapshot before them, and signed comparisons after narrowing. This is measured source-to-output evidence; no compiler-pass attribution beyond the inspected generated assembly is asserted.
