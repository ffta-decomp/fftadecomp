# Prepare a script family once, recover each decision separately

The source94 cohort produced eight locally whole-exact pure-C methods totaling
762 original bytes under fixed O2. These are local gates, not a claim that all
eight were integrated. Three of eight first recorded attempts were immediately
exact. Five matched on their first effective C formulation after accounting for
linkage, schema or terminal-alignment repairs. Keep those measurements separate:
the failed commands and preparation remain part of delivery time.

The useful shared preparation was a verified original descriptor/dispatcher
contract, readable original ASM envelopes, typed helper interfaces and explicit
existing-padding ownership. The methods still required their own branch targets,
widths, reload sites and complete return/literal boundaries. Neither adjacent
addresses nor descriptor spacing established those boundaries.

## Reuse the caller contract, not the predicate

The nested dispatcher independently advances the script PC by each command's
descriptor length. The handler conditionally adds a little-endian displacement
to the PC halfword. Preserve wrapping and the original point at which command
bytes and the PC are read, especially after helper calls. Do not add the normal
descriptor advance inside each recovered handler.

The [current-unit condition](../worker3/CoreScript94_0000A2F0.md) keeps the actual
context-loaded unit pointer for both identity and the byte257 read. The
[actor-counter condition](../sol_b/Script94_0000A420.md) reloads the actor's unit
after a helper and accumulates byte contributions into an integer sum; narrowing
that sum to a byte would change the contract. Their common script-PC tail does
not authorize sharing their distinct predicates or snapshot rules.

## Recover the promoted value's complete use chain

The [selected-unit index](../main/selected-unit-script-index.md) first performs
an unsigned-byte bounds check, then signed indexing from the same shifted value.
Keeping a signed-byte local and casting only the bounds check restored the
original reuse; an unsigned local with a later signed cast added a shift and
four bytes. This is an observed source-to-output result, not a general rule to
make indices signed or an attributed compiler-pass trace.

The [fixed-object condition](../sol_c/CoreScript94_0000A564.md) preserves the
original EWRAM base plus halfword offset through the actual typed object. Read
the field only after the original helper/null guard. Do not replace a proved
object access with a numerically equivalent pointer or invent a field meaning.

For [threshold branches](../sol_b/Script94_0000A36C.md), preserve which accepted
edge bypasses the result test and which paths enter the shared test. Equivalent
Boolean descriptions can obscure the original branch orientation. Establish
the complete CFG before trying another expression spelling.

## Remove repeated admission mistakes

Resolve actual helper exports from the current symbol inventory before the
first link. A proved function address and role do not guarantee that its inferred
C name is exported; use the existing declaration-only linkage mechanism when
needed, without recovering or counting the helper body.

Keep already selected trailing padding as its own component. If the ELF proves
the full function ends before compiler-only section padding, use the existing
strict normalization metadata and preserve the separate retail padding proof.
Never trim an instruction, literal, epilogue or unexplained extra byte. Several
cohort retries corrected this boundary bookkeeping without changing C logic.

Use the current candidate schema instead of adding speculative keys. Record a
schema or linkage failure as setup cost, not as a rejected source hypothesis;
record the next exact decision at its real time rather than erasing that cost.

The cohort supports reusing a prepared family contract while splitting complete
methods among actors. It does not establish a model advantage or a fivefold
speedup. Source-envelope preparation, administrator dispatch, handoff gaps and
publication remain charged separately from per-method claim intervals; some
early preparation time is not isolated and must not be called idle.
